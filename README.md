# Help Desk Ticket Manager

Desktop application developed in Python for managing IT support tickets.

The project was created as a personal learning project to practice Python, GUI development, SQL, and database management in a practical IT support scenario.

## Features

- Create new IT support tickets
- Validate required fields before saving
- Store tickets in a SQLite database
- Display tickets in a table using Tkinter Treeview
- Filter tickets by title, priority, and status
- Edit existing tickets
- Change ticket status between Open and Closed
- Delete one or multiple selected tickets
- Visual distinction between open and closed tickets

## Technologies

- Python
- Tkinter
- SQLite
- SQL
- Git

## Project Structure

- `main.py` – graphical interface and application logic
- `database.py` – database connection and SQL operations
- `ticket.py` – ticket-related logic/classes
- `ticket_manager.db` – SQLite database
